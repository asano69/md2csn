- `**a *b* c**` は、空白を括弧の外に出すため [* a] [*/ b] [* c] になります。ご提示の表の [* a ][*/ b][* c] とは空白の位置が違います。
- `***a***` は Emphasis と Strong の入れ子として生成されると想定しています。どちらの順でも結果は [*/ a] になります。

- 見出しとテーブルのセルの装飾は、従来どおり落とします。 タイトル行はソース文字列のまま出力するので変わりません。

- [[wikilink]] は装飾内で [* [a]] のようにネストします。 通常リンクと CodeSpan は装飾を付けず、今のまま出力します。

- 装飾の中のテキストに ] が含まれると括弧が壊れます。 これは見出しと同じ制限で、今回は対応しません。
